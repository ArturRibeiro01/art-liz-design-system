## Compor uma interface

Use as receitas de [formulários](receitas-formularios.md), [dados/filtros](receitas-dados.md), [Dialog/Drawer](receitas-superficies.md) e [confirmação](receitas-confirmacao.md). Elas combinam as peças sem repetir as matrizes de props do MDX. O [primeiro projeto](primeiro-projeto.md) mostra navegação por React Router.

Consulte [estado e limites](estado-e-limites.md) antes de escolher Cascader, Transfer, DateTimePicker ou Chart. O [catálogo Icons](icones.md) é uma exportação adicional; não é contado entre os 37 componentes.
