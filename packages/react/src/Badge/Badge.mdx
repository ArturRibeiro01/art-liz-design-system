# Badge

Badge apresenta um marcador compacto para destacar um estado, categoria ou quantidade junto a outro conteúdo. Use intent para escolher o tom semântico e texto para comunicar o significado.

## Importação

```tsx
import { Badge } from '@art-liz/react'
```

## Uso

```tsx
import { Badge } from '@art-liz/react'

export function Exemplo() {
  return (
    <Badge intent="success" size="medium">
      Ativo
    </Badge>
  )
}
```

## Orientações

Badge não anuncia alterações automaticamente. Para feedback dinâmico, considere Message ou Alert; o significado não deve depender apenas da cor.

Use size="small", "medium" ou "large". O padrão small mantém as dimensões anteriores; medium e large ampliam o espaçamento e a tipografia. Badge continua sendo informativo, sem interação própria.
