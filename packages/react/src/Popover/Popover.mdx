# Popover

Popover apresenta conteúdo complementar junto a um acionador, sem transformar a interação em um fluxo modal. Use-o para detalhes curtos, explicações ou controles contextuais.

## Importação

```tsx
import { Popover } from '@art-liz/react'
```

## Uso

```tsx
import { Popover } from '@art-liz/react'

export function Exemplo() {
  return (
    <Popover trigger="Ver detalhes" title="Sobre este projeto">
      <p>Uma biblioteca compartilhada entre os projetos pessoais.</p>
    </Popover>
  )
}
```

## Orientações

trigger é o conteúdo do botão criado pelo componente: não passe outro botão dentro dele. A abertura é interna e onOpenChange informa transições. Escape e clique externo fecham o conteúdo; exige a Popover API nativa.
